# GIT-TUTOR - Online Learning Platform

![GIT-TUTOR Logo](images/logo.png)

GIT-TUTOR is a modern, responsive online learning platform designed to help students and professionals enhance their skills through comprehensive courses in various domains. The platform offers a user-friendly interface, interactive learning materials, and a robust course management system.

## 🌟 Features

- **Responsive Design**: Fully responsive layout that works seamlessly on desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean and intuitive user interface with smooth animations and transitions
- **Course Categories**: Wide range of courses including:
  - Blockchain Technology
  - Graphics Design
  - Finance
  - Marketing
  - Music
  - Business
- **Interactive Learning**: Engaging course materials with practical examples
- **Student Testimonials**: Real feedback from students about their learning experience
- **Expert Faculty**: Experienced professors and industry experts
- **Contact Form**: Easy communication with the support team
- **Social Media Integration**: Connect with us on various social platforms

## 🚀 Technologies Used

- **Frontend**:
  - HTML5
  - CSS3
  - JavaScript
  - Font Awesome Icons
  - Swiper.js (for testimonials)
  - Google Fonts (Montserrat)

## 🛠️ Setup and Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/vedantdalavi14/Web-Project
   ```

2. Navigate to the project directory:
   ```bash
   cd Web-Project
   ```

3. Open the project in your preferred code editor

4. Launch the project:
   - Open `index.html` in your web browser
   - Or use a local development server
